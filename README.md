# 🤖 Python Automações

Repositório destinado ao desenvolvimento de automações para otimização de processos utilizando Python.

## 🚀 Tecnologias

- Python
- Pandas
- Selenium
- OpenPyXL
- PdfPlumber
- PyAutoGUI
- Git e GitHub

## 📂 Projetos

### 📧 Automação de Envio de Emails

Automação responsável por:

- Ler dados de uma planilha Excel
- Montar emails automaticamente
- Preencher destinatários
- Enviar mensagens via Outlook

### 🔎 Consulta Automática de CNPJ

Automação desenvolvida com Selenium para:

- Acessar páginas web
- Inserir CNPJ automaticamente
- Gerar certidões
- Baixar documentos em PDF
